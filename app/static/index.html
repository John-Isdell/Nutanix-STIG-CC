Prism Central API-key requirements

API-key authentication requires Prism Central pc.2024.3 or later with supported AOS 7.0+ clusters. Older Prism Central releases use Username/Password. Nutanix does not provide Prism Central UI controls for creating these service-account keys.

  1. Create a dedicated service account with POST /api/iam/v4.0/authn/users and userType: SERVICE_ACCOUNT.
  2. Create its API key with POST /api/iam/v4.0/authn/users/{extId}/keys.
  3. Save the generated key immediately. Its secret is returned once and cannot be retrieved later.
  4. Grant the service account the least-privilege cluster-view role with POST /api/iam/v4.0/authz/authorization-policies. A key without an authorization policy authenticates but cannot read inventory.
  5. Select API Key below. The Control Center sends it only as X-Ntnx-Api-Key for this read-only check and never saves it.

Account, key, and policy creation are intentionally not automated here because they create persistent IAM objects. See the client guide for the complete operator procedure.

Held only for the current request. It is not written to configuration, logs, audit history, or evidence.
